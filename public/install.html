تثبيت تطبيق فواتير الفرع

إذا لم تظهر نافذة التثبيت تلقائياً، اتبع الخطوات حسب جهازك:

  1. أندرويد / Chrome: افتح الرابط عبر HTTPS ثم قائمة Chrome ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
  2. آيفون / Safari: زر المشاركة ← إضافة إلى الشاشة الرئيسية ← إضافة.
  3. تأكد أن الرابط يبدأ بـ https:// — التثبيت لا يعمل على http إلا على localhost.
  4. بعد التثبيت سيظهر الشعار على الشاشة الرئيسية.
