# تفاصيل فواتير الفرع

نظام عربي (RTL) مبني على ملف `نموذج_فواتير_الفرع.xlsx` المرفق: شاشة إدخال **«تفاصيل فواتير الفرع»** (جدولان بـ 10 صفوف لكل منهما + قسم الشفت صباحي/مسائي + حقول محسوبة)، مع دورين فقط: **محاسب** و**كاشير**.

## التشغيل
```bash
npm run dev     # الواجهة 5173 + الخادم 3001
```
أو للإنتاج:
```bash
npm run build && npm start   # افتح http://localhost:3001
```

> للرابط الحقيقي: تثبيت التطبيق (PWA) يحتاج **HTTPS** (إلا على localhost).

## البدء الفعلي (بدون بيانات تجريبية)
1. أول فتح → شاشة الإعداد الأولي: اسم المحاسب، بريده، كلمة المرور، اسم الفرع الرئيسي.
2. من لوحة المحاسب: أضف الفروع ثم الكاشيرات بأيميلاتهم واربط كل كاشير بفرعه.
3. الكاشير يسجّل الدخول ويدخل الفواتير؛ فرعه مثبّت ولا يرى غيره.

## الصلاحيات
| | المحاسب | الكاشير |
|---|---|---|
| شاشة الإدخال | معاينة فقط | ✅ إدخال فقط |
| الفروع والمستخدمون | ✅ | ❌ 403 |
| التقارير والتصدير والطباعة | ✅ | ❌ 403 |
| رؤية الفروع الأخرى | ✅ | ❌ فرعه فقط |

الخادم يتجاهل أي `branch_id` يرسله الكاشير ويستخدم فرع حسابه دائماً، ويرفض أي طلب غير `POST /api/invoices` له.

## الحقول (حسب ملف Excel)
- **تفاصيل فواتير الفرع (1 و2)** — 10 صفوف لكل جدول:
  المورد أو بيان الصرف | الفواتير | المدفوعات | الباقي (محسوب = الفواتير − المدفوعات) | ملاحظات + الإجمحاسب.
- **البيانات**: اسم الفرع (تلقائي من الحساب)، التاريخ، اليوم (يُشتق من التاريخ).
- **الشفت**: صباحي / مسائي — إجمحاسب الكاش، الشبكة، الفرع (الصرف)، صافي الكاش (محسوب = الكاش − الصرف)، إجمحاسب المبلغ (محسوب = صافي الكاش + الشبكة) + الإجمحاسب.
- الحقول المحسوبة تتحدث فوراً أثناء الإدخال، وتُحفظ مع النموذج وتظهر في التقارير والـ Excel والطباعة.

## التقارير (للمحاسب فقط)
- فلاتر: الفرع، الكاشير، من/إلى تاريخ، بحث عام.
- تقرير مستقل لكل حقل (22 حقلًا).
- Excel لنتيجة الفلاتر/نموذج مفرد/تقرير حقل، طباعة PDF (A4 RTL مع التوقيعات)، ومشاركة واتساب.

## PWA
Manifest + Service Worker + أيقونات. شريط تثبيت غير حاجز يظهر فور الفتح (المتصفحات لا تسمح بالإجبار بدون موافقة ضغطة واحدة).

قاعدة البيانات: `server/data/fawateer.db`. غيّر `JWT_SECRET` في `server/index.js` قبل النشر.
